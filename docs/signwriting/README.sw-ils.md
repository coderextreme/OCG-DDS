## 2. Any Other International Sign Language
In Lattice's **SignWriting** channel, pick **`Custom Sign Language (Any ISO 639-3 / Name)...`** and enter any sign language code or name (for example `KSL`, `FSL`, `CSL`, `NZSL`, `SASL`, `LSQ`, `LIS`, `NGT`, `SSL`, `VGT`, `RSL`, `UKS`, etc.) to render vertical or horizontal SignBoxes + FSW + Unicode SWU tagged for that community.

```bash
git clone https://github.com/coderextreme/OCG-DDS && cd OCG-DDS && npm install && npm run dev
```
