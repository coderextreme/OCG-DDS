# Доступный распределённый редактор графов с Object-Capabilities (Русский)

**Проект:** Lattice · **Репозиторий:** <https://github.com/coderextreme/OCG-DDS> · **Контакт:** `yottzumm@gmail.com`

Это приложение было создано быстро с помощью ИИ. Автор пока не читает по Брайлю и не владеет SignWriting и приглашает незрячих, слепоглухих и глухих пользователей протестировать систему, дать обратную связь или стать соруководителями проекта.

## Доступность для незрячих, слепоглухих и глухих пользователей
- **Экранные дикторы и клавиатура:** Переключение модулей (`Alt+1`–`Alt+4`), консоль редактирования (`Alt+E`), линейный обход графа, хеш-кольца и дерева Меркла (`ArrowLeft`/`ArrowRight`, `Home`/`End`), справка (`?`) и `aria-live`-оповещения.
- **Шрифт Брайля:** 40-ячеечный буфер **Braille** (кнопка **Show Dots** — Юникод Брайль `⠁`–`⠿`) и 6-точечный ввод Перкинса (`F D S` / `J K L`).
- **Protactile (PT) для слепоглухих:** Полное отсутствие зависимости от звука, режим **High Contrast**, пространственные зоны касания (`Zone A/B/C`) и тактильные импульсы (**Pulse Haptics**).
- **Жестовые языки и SignWriting:** Вывод **ASL** и **SignWriting** (`FSW`, `Unicode SWU`, 2D-SVG) с поддержкой пресетов и любого пользовательского жестового языка (например, `RSL` — РЖЯ).

## Установка и запуск
Требуются Node.js с `npm` (<https://nodejs.org/>) и Git.
```bash
git clone https://github.com/coderextreme/OCG-DDS
cd OCG-DDS
npm install --package-lock-only --allow-remote=all
npm ci
npm run dev
```
Сборка: `npm run build && npm run preview`

## Предупреждения
Состояние графа сейчас хранится только в оперативной памяти браузера; удалённое сохранение и аудит безопасности кода ещё не проведены.
