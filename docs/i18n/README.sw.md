# Kihariri cha Grafu Iliyosambazwa Kinachofikika cha Object-Capability (Kiswahili)

**Mradi:** Lattice · **Hifadhi:** <https://github.com/coderextreme/OCG-DDS> · **Barua pepe:** `yottzumm@gmail.com`

Programu hii iliundwa haraka kwa msaada wa AI. Mwandishi bado hawezi kusoma Breli au SignWriting, na anakaribisha jamii za Wasioona, Viziwi-Wasioona, na Viziwi kujaribu na kusaidia kuongoza mradi huu.

## Ufikikaji
- **Visoma Skrini na Kibodi:** `Alt+1`–`Alt+4`, `Alt+E`, `ArrowLeft`/`ArrowRight`/`Home`/`End`, `?`, na matangazo ya `aria-live`.
- **Breli (Braille):** Kihifadhi cha seli 40 (**Show Dots** `⠁`–`⠿`) na kuingiza kwa Perkins nukta 6 (`F D S` / `J K L`).
- **Protactile (PT):** Bila kutegemea sauti, hali ya **High Contrast**, kanda za mguso (`Zone A/B/C`), na mitetemo (**Pulse Haptics**).
- **Lugha za Ishara & SignWriting:** **ASL** na **SignWriting** (`FSW`, `Unicode SWU`, visanduku vya 2D SVG) kwa lugha yoyote ya ishara ya kimataifa (k.m., `KSL`, `TSL`).

## Usakinishaji
```bash
git clone https://github.com/coderextreme/OCG-DDS
cd OCG-DDS
npm install --package-lock-only --allow-remote=all
npm ci
npm run dev
```
*(Kwa sasa inafanya kazi kwenye kumbukumbu ya kivinjari pekee; ukaguzi wa usalama unahitajika.)*
