# Alirebla Disdona Grafa Redaktilo kun Object-Capabilities (Esperanto)

**Projekto:** Lattice · **Deponejo:** <https://github.com/coderextreme/OCG-DDS> · **Kontakto:** `yottzumm@gmail.com`

Ĉi tiu aplikaĵo estis rapide kreita kun helpo de AI. La aŭtoro ankoraŭ ne legas Brajlon aŭ SignWriting kaj bonvenigas blindajn, surdblindajn kaj surdajn komunumojn por testi kaj kunestri la projekton.

## Alirebleco
- **Ekrankursoj & Klavaro:** `Alt+1`–`Alt+4`, `Alt+E`, `ArrowLeft`/`ArrowRight`/`Home`/`End`, `?`, kaj `aria-live`.
- **Brajlo:** 40-ĉela **Braille**-bufro (**Show Dots** `⠁`–`⠿`) kaj 6-punkta Perkins-enigo (`F D S` / `J K L`).
- **Protactile (PT):** Sen sondependo, reĝimo **High Contrast**, tuŝzonoj (`Zone A/B/C`) kaj haptiko (**Pulse Haptics**).
- **Signolingvoj & SignWriting:** **ASL** kaj **SignWriting** (`FSW`, `Unicode SWU`, 2D SVG) por iu ajn internacia aŭ propra signolingvo (ekz. `Signuno`).

## Instalado
```bash
git clone https://github.com/coderextreme/OCG-DDS
cd OCG-DDS
npm install --package-lock-only --allow-remote=all
npm ci
npm run dev
```
